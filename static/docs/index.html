🖼️ Générer une image

POST /generate
ParamètreTypeRequisOptionsDéfaut
promptstring✅Libre-
ratiostring❌9:16, 16:9, 1:19:16
formatstring❌jpg, jpeg, pngjpg

Exemples :

curl -X POST "https://gpt-1-m8mx.onrender.com/generate" \\
  -H "Content-Type: application/json" \\
  -d '{"prompt": "A beautiful sunset over mountains"}' \\
  --output image.jpg

🪄 Éditer une image existante

ParamètreTypeRequisDescriptionDéfaut

formatstring❌jpg, jpeg, pngjpg

Conversion base64 :

base64 -w 0 -i image.jpg

Exemple cURL :

curl -X POST "https://gpt-1-m8mx.onrender.com/edit" \\
  -H "Content-Type: application/json" \\
  -d '{"image": "<base64_string>", "prompt": "Enhance realism"}' \\
  --output edited.jpg

🚀 Intégration JavaScript

class ImageGenAPI {
  constructor() {
    this.baseUrl = "https://gpt-1-m8mx.onrender.com";
  }

  async generate(prompt, ratio = '9:16', format = 'jpg') {
    const response = await fetch(`${this.baseUrl}/generate`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ prompt, ratio, format })
    });
    return await response.blob();
  }

  async edit(imageBase64, prompt, format = 'jpg') {
    const response = await fetch(`${this.baseUrl}/edit`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ image: imageBase64, prompt, format })
    });
    return await response.blob();
  }
}
